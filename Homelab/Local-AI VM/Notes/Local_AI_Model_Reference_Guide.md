## Vision Model Candidates — Benchmarked on This Hardware (2026-09-03)

**Real-world results, not estimates.** All models below were tested with the same 15-image evaluation set (mixed photos, screenshots, game/render characters, and handwritten text), hand-graded 1-5 for description accuracy. Inference time is per-image, single-response wall-clock time on this machine (varies heavily with image resolution — see notes). Full per-image breakdown, notes, and exact wording of each response is in `vision-model-accuracy-test-set.md`; this table holds headline/summary numbers only.

| **InternVL2 (8B+)**<br>8B+ | Ungraded (see note) | N/A | Responses were consistently truncated/cut off before completion across all 15 test images, making accuracy grading unreliable — the partial output that did generate looked plausible, but no full response was captured to grade fairly. | **Con:** Some unresolved issue (likely a generation-length/stop-token or memory-pressure problem) prevented complete responses on this setup; needs further investigation before this model can be fairly evaluated. | Not currently usable for real evaluation on this hardware until the truncation issue is diagnosed. |

**Key findings:**
- **Qwen2-VL-7B was the most accurate model tested**, but also by far the slowest (~206s/image average, with the largest/highest-resolution test images pushing well past 500s and sometimes truncating before the model finished its own sentence).
- **MiniCPM-V-2 stood out for accuracy-per-parameter** — at under 3B parameters it beat both Gemma 3 4B and Qwen2-VL-2B on average grade, though it wasn't the fastest.
- **Gemma 3 4B was the best speed/quality balance** among models that both loaded and completed reliably.
- **Qwen2-VL-2B was the least reliable of the working models** — good at raw OCR/transcription but the most prone to fabricating what transcribed text or stats actually meant, which is a more deceptive failure mode than a vague or hedged wrong answer.
- **Inference time scales heavily with image resolution/size** across all models — the two largest test images (4948x3711 and 2105x3000) were consistently the slowest per-model, in some cases 5-10x the typical time and occasionally causing truncated responses even in otherwise-accurate models (e.g. Qwen2-VL-2B, Qwen2-VL-7B both got cut off on these two images despite scoring well on partial content).
- **LLaVA-1.6 13B is not viable on this 8GB VM** — OOM-killed on load, consistent with the RAM budget concerns already flagged for 13B+ text models in this guide.
- **InternVL2 8B+ could not be fairly graded** — responses were truncated on every one of the 15 test images. Needs further investigation (possibly a stop-token/config issue or memory pressure during generation) before drawing conclusions about its accuracy.

## Model Ecosystem & Creator Breakdown

| Company / Creator | Primary Model Family | Design Philosophy & Unique Traits | Best Used For |
| :--- | :--- | :--- | :--- |
| **Meta** | Llama | Focuses on massive, high-quality human data sets. Industry standard for open-source AI, offering natural conversational flow and robust instruction following. | General-purpose chatbots, creative writing, and everyday assistant tasks. |
| **Alibaba** | Qwen | Optimized for math, multilingual tasks, and programming. Designed to obey system prompts strictly and excel at structured outputs. | Code assistance, data parsing, and generating strict JSON formatting. |
| **Microsoft** | Phi | Trained on high-density synthetic "textbook" data, allowing smaller parameter models to execute complex logical reasoning. | Logic puzzles, reading comprehension, and constrained hardware setups. |
| **DeepSeek** | DeepSeek-Coder / DeepSeek-R1 | Focuses on extreme inference efficiency and chain-of-thought deduction, outputting explicit "thinking" steps before answering. | Algorithmic programming, math problem solving, and logical deduction. |
| **Google** | Gemma | Built using Gemini-derived architecture. Utilizes dense feature representation to compress high knowledge levels into small model frames. | Academic text processing, precise summarization, and data extraction pipelines. |
