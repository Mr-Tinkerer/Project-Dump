## Grading Rubric

For each answer, record:
- **Correctness** (factual/math/code items): Correct / Partially Correct / Incorrect
- **Quality** (open-ended items): 1–5 scale
- **Format compliance** (JSON/code items): Pass / Fail
- **Notes**: confident-but-wrong hallucinations are worth flagging separately from honest gaps or refusals — a model that says "I'm not sure" is more trustworthy long-term than one that fluently invents an answer.
